工作方法诊断

按约束强弱判断数据可信度

数据不完整时，哪些指标还能用于行动，哪些只能提示风险？

先判断数据怎样产生、由什么约束，再决定它能支持什么结论。

方法步骤

  1. 01

    识别强约束数据，例如交易与结算。

  2. 02

    识别需要抽核的中约束数据。

  3. 03

    标出依赖人工、容易漏记的弱约束数据。

  4. 04

    让分析输出与证据等级对应。

适用场景

  • 门店经营诊断
  • 库存与损耗分析
  • 经营报表设计

使用边界

  • 风险提示不能包装成准确库存或预测。
  • 数据质量问题需要业务流程共同修复。
